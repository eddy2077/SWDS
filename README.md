# 知识图谱导师

一个基于 HarmonyOS 的学习辅助应用：输入一个学习主题，即可生成知识图谱、学习路径和自适应测验，帮助学习者理解知识结构并持续追踪学习进度。

## 功能

- 基于学习主题生成知识图谱
- 按知识依赖规划学习路径
- 生成练习题并记录学习历史
- 提供 AI 学习助手与可视化布局示例

## 开始使用

1. 安装与本项目兼容的 DevEco Studio 和 HarmonyOS SDK。
2. 用 DevEco Studio 打开 `MyApplication` 目录。
3. 同步项目依赖后，在模拟器或设备上运行。

## AI 服务配置

本仓库不包含任何 API 密钥。不要将密钥写入应用源码或提交到 Git。

生产环境应通过自己的后端服务调用 AI 接口，避免把服务端凭据打包到客户端应用中。
